# Ferramenta Financeira La Bicyclette

Ferramenta estatica para gerar analises financeiras no navegador.

## Como usar

1. Abra `admin.html`.
2. Selecione os PDFs do Linx nos campos corretos.
3. Selecione os extratos bancarios, se houver.
4. Clique em `Importar mes`.
5. Abra o dashboard gerado.
6. Baixe o pacote `.financeiro.json` se quiser guardar ou compartilhar a analise.

Os PDFs sao processados no navegador com PDF.js. Nenhum PDF e enviado para servidor.
